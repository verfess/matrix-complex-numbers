# Matrix Complex Numbers

Консольное Java-приложение для выполнения математических операций над матрицами комплексных чисел.

## Возможности

### Комплексные числа — `ComplexNumber`

- Создание и копирование комплексных чисел.
- Получение действительной и мнимой частей.
- Арифметические операции: сложение, вычитание, умножение и деление.
- Проверка комплексного числа на ноль.
- Форматированный вывод, например `3.00 + 2.00i`.

### Матрицы — `ComplexMatrix`

- Создание и копирование матриц произвольного положительного размера.
- Сложение и вычитание матриц.
- Умножение матриц с проверкой совместимости размеров.
- Деление матриц через умножение на обратную матрицу.
- Транспонирование.
- Вычисление определителя методом Гаусса.
- Вычисление обратной матрицы методом Гаусса-Жордана.
- Ввод матриц через консоль и форматированный вывод.

### Консольный интерфейс

Главный класс `MatrixComplexNumbers` предоставляет интерактивное меню:

1. Сложение матриц.
2. Вычитание матриц.
3. Умножение матриц.
4. Деление матриц.
5. Транспонирование матрицы.
6. Вычисление определителя.
7. Вычисление обратной матрицы.
0. Завершить работу.

## Установка и запуск

Для работы требуется JDK 8 или выше и терминал или командная строка.

Клонируйте репозиторий:

```
git clone https://github.com/verfess/matrix-complex-numbers.git
cd matrix-complex-numbers
```

Скомпилируйте исходные файлы:

```
javac ComplexNumber.java ComplexMatrix.java MatrixComplexNumbers.java
```

Запустите приложение:

```
java MatrixComplexNumbers
```

После запуска появится консольное меню. Выберите нужную операцию и следуйте инструкциям программы.
